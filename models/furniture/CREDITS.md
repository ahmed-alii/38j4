# Furniture model credits

Each `.json` file holds one glTF binary model, base64-encoded, because artifact pages serve `.json` but not `.glb`. Textures were shrunk to 512 or 1024 px WebP and meshes compressed with meshopt (gltf-transform). Shapes and sizes are unchanged.
